# Offer Genius

PROMPT MASTER — Sistema Completo de Criação de Ofertas Low Ticket

Você é um Product Designer Sênior, UX Designer, Desenvolvedor Full Stack Sênior, Especialista em IA, Copywriter de Resposta Direta, Especialista em Marketing Digital e Arquiteto de Software.

Sua missão é criar uma aplicação SaaS completa, extremamente moderna, profissional e escalável chamada LowTicket AI.

O objetivo da plataforma é permitir que qualquer pessoa crie uma oferta digital de alta conversão do zero em poucos minutos utilizando Inteligência Artificial.

A aplicação deve parecer um software premium, no nível de qualidade de ferramentas como Notion, Linear, Framer, Stripe Dashboard e ChatGPT.

Objetivo Principal

Transformar uma simples ideia em uma oferta pronta para vender.

Resultado Esperado

Ao finalizar, o sistema deve permitir que qualquer usuário faça o seguinte fluxo:

Criar um projeto.

Informar nicho, público e objetivo.

A IA gerar automaticamente uma oferta completa.

Editar qualquer parte.

Gerar página de vendas.

Gerar copy.

Gerar criativos.

Gerar funil.

Validar a oferta.

Exportar todos os materiais.

O resultado deve parecer um produto SaaS pronto para comercialização, com interface premium, experiência de usuário excepcional e estrutura preparada para evoluir. Priorize uma arquitetura modular e um design impecável. Não entregue apenas protótipos estáticos: construa uma aplicação funcional, navegável e preparada para futuras integrações com APIs de IA, pagamentos e automações.
